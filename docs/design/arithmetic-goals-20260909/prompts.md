# Arithmetic goal mockups

Preview concepts generated with the built-in image-generation tool. Not implemented or released. Scores and copy are illustrative.

## Shared prompt

Use case: ui-mockup. Create ONE polished landscape tablet-screen mockup for a children's basic arithmetic browser game called "Place by Place". This is a design concept, not a photo of a device: straight-on screen only, no bezel, no perspective. Warm ivory background, charcoal rounded sans-serif typography, restrained teal controls, cheerful carefully illustrated game art. Clear readable child-friendly UI, large touch targets, spacious layout. Header reads "Place by Place", small subtitle "Basic addition & subtraction". Upper half is a beautiful goal illustration specific to this concept; lower half shows the SAME unanswered practice question "7 − 5 = ?" with a numeric answer box, compact 3-column keypad 1–9 then Clear,0,backspace, a teal "Check" button and outlined "Show me" button. Small "Question 4 of 10". No other arithmetic problems, no visible answer to current question, no timers, no ads, no difficulty upgrades, no dense dashboard. All essential content fits one screen. A small top-left concept label must identify this variant. Make the goal area genuinely engaging and visually dominant while the exercise stays readable.
