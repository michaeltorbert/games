## Product and interaction thesis

- Keep the released app's calm, rounded, child-friendly visual language and its short adaptive sessions.
- Make the mathematics physically truthful: within each rendered question, one visible unit `u` defines a cube (`u × u`), a rod (`u × 10u`), and a flat (`10u × 10u`). Responsive scaling changes `u` for the whole representation, never one block type independently.
- Add variety through recognition and transfer, not speed pressure: number words use four plausible choices and zero-pattern transfer starts with visible H–T–O columns before moving to unlabelled, shuffled blocks.
- A wrong choice never earns first-try/mastery credit. Hints move from strategy to structure to an explicit answer, and any miss schedules later review.
- Preserve the existing eight-question adaptive promotion/demotion window. Do not add a five-answer fast path or a Fluent Start default.
