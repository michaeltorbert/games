Kayak Reporting

Privacy policy

Last updated: October 1, 2026

This policy describes the Kayak activity-reporting feature and the game owner's Google connection. Players are not asked to connect a Google account.

Information reported by the game

The game sends an event when a game starts, a level starts or a level is completed. Its reports include the event, timestamp, level number and name, score, game version, device type, screen dimensions, browser language, timezone, platform, browser user-agent and referring page when available. Level-completion requests also include the collectible count, which is not stored in the existing spreadsheet columns. The reporting service obtains the request's IP address.

The game also stores progress and high scores locally in the player's browser. The game does not ask players for a name, email address or Google account credentials. Referring-page URLs may contain information supplied by the referring site.

Why the information is used

The game owner uses these reports to monitor game activity and diagnose reporting problems. Activity is appended to a Google spreadsheet, followed by a notification to the owner's fixed email address. Cloudflare notifications may include an approximate city, state or region, and country inferred from the request's IP address in the email subject. This is not GPS location and may reflect a VPN or mobile network. Missing location information does not stop reporting. The location estimate is not added to spreadsheet rows or application logs. Reporting data is not used for advertising or sold.

Google account access

Only the owner authorizes the reporting connection. Google Sheets permission allows access to spreadsheets in that account; the service uses that permission to append reports to one configured Kayak usage spreadsheet. Gmail send permission is used to send the fixed notification to the owner. The service does not request permission to read the owner's Gmail inbox.

The Cloudflare service stores authorization credentials as private server-side secrets. They are not included in the game code or sent to players. Credentials are used to obtain the access needed for these reporting actions. Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Service providers and storage

Kayak v1.1.38 and later report through Cloudflare Workers, which writes to Google Sheets before sending a Gmail notification. Older copies still report through the existing Pipedream workflow, which remains active while players update. These providers process the information needed to deliver the reports and operate their services.

The Cloudflare service's application logs record event types, outcomes, failure stages and status codes. They omit report bodies, IP addresses and credentials. Provider infrastructure may process request information under its own policies.

The Cloudflare service also stores a UTC date and an email-attempt count in Cloudflare to limit notification volume. This counter contains no player details. Its email cap can suppress notifications while activity continues to be recorded in the spreadsheet.

Retention and controls

Pipedream retains workflow execution history, which can include incoming report payloads and request information. That history remains subject to Pipedream's retention settings and policies even after Pipedream is retired. Deleting spreadsheet rows or emails does not delete Pipedream execution history.

There is no automatic deletion schedule for spreadsheet rows or notification emails. They remain in the owner's account until the owner deletes them. The owner can revoke the Google connection through Google Account permissions, which stops authorized API access. Revocation does not remove existing rows or emails. Browser-local progress can be removed by clearing this site's browser data.

Questions and deletion requests

Contact the maintainer through the project's issue tracker. Issues are public: do not post credentials, your IP address, email contents or other private information there. Ask for a private way to provide details if needed.
