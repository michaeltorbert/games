# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Running the Games

No build system or dependencies required. Each game is a self-contained HTML file — open directly in a browser:

```bash
open football/football-math.html
open kayak/kayak-adventures_1.html
open prague/prague_bike_panic.html
```

## Architecture

Every game follows the same pattern: **a single `.html` file** containing all CSS (in `<style>`), all JavaScript (in `<script>`), and markup. There are no external dependencies beyond a Google Fonts CDN link in `football-math.html`. No bundler, no framework, no build step.

All games are mobile-friendly with touch controls and `user-scalable=no` viewport settings.

## The Games

**`football/football-math.html`** — Football Math
A multiple-choice math quiz game with a football theme. Game state is tracked in a single `state` object. Each "play" is generated by `buildPlay()`, which randomly selects from four question types (`buildType1`–`buildType4`) covering yard-line arithmetic, down-and-distance, drive yardage, and distance-to-end-zone. `handleAnswer()` drives the play-result logic (first downs, turnovers, touchdowns). The field is drawn with DOM elements (no canvas). Overlays handle touchdown and end-of-game screens.

**`kayak/kayak-adventures_1.html`** — Sydney & Michael's Kayak Adventures
A canvas-based kayak game with a HUD, level banner, postcard overlay screens, and an on-screen D-pad for mobile. Uses a `<canvas>` element for rendering with a `requestAnimationFrame` game loop.

**`prague/prague_bike_panic.html`** — Prague Bike Panic
A canvas endless-runner. Two selectable characters (Michael and Sydney) with different stats (`jumpV`, `moveSpd`, `invFrames`, `maxHits`). Core globals: `STATE` (title/playing/dead), `OBS` (obstacle array), `RAIN`, `BGL` (parallax layers), `PUDDLES`. Input is unified through a `K` (keys held) and `JP` (just-pressed) object, shared by keyboard listeners and mobile `<button>` touch/mouse events. Speed increases over time via `gameSpeed`.
